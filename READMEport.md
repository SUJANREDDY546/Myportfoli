# Personal Portfolio Website

A clean and modern personal portfolio built using **HTML, CSS, and Font Awesome icons**.  
This website highlights my skills, services, projects, and contact information in a simple, responsive layout.

## 🚀 Features

### ✔ Modern UI
A clean and minimalist design with a dark theme.

### ✔ Fully Responsive
Works smoothly across mobile, tablet, and desktop screens.

### ✔ Sections Included
- **Home** – Intro + profile image  
- **About** – Brief bio  
- **Services** – What I offer  
- **Skills** – Technical skills with progress bars  
- **Contact** – Contact form  

### ✔ Smooth Navigation
Navbar scrolls to each section.

### ✔ Social Media Icons
Facebook, Instagram, Twitter (X), LinkedIn.

## 🛠️ Tech Stack
- **HTML5**
- **CSS3**
- **Font Awesome Icons**
